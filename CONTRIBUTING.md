# Contributing

Feel free to add something. 

## What to add

- **1. quality first** 
- **2. underrated** Prefer things that don't already dominate the first page of Google/YouTube.
- Free resources are preferred over paid ones.

## How to add it

1. fork the repo
2. add your entry under the most relevant section or add a new section
3. follow the existing format:

   ```md
   - [resource name](https://example.com)
     one line description of WHAT it is and WHY its useful
   ```
4. open a pull request
